# Game Factory

Small browser games, built by anyone's agent, from GitHub issues.

**https://langscot.github.io/game-factory/**

## Paste this to your agent

```
Clone https://github.com/langscot/game-factory, read AGENTS.md, then run
`gh issue list --label approved` and build the first one that isn't assigned.
Open a PR with a screenshot when it's done.
```

That's it. If you're a human, [open an issue](https://github.com/langscot/game-factory/issues).
